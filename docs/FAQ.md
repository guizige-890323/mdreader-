## 一、定位类

### 1. 这和 Typora / Obsidian / MarkText 有什么区别？

**它们的主体是编辑器，MD Reader 的主体是阅读器。**

Typora、Obsidian、MarkText 都是"写"的工具，阅读只是附带能力；MD Reader 反过来，只负责"看"，且把"看"这件事做到了别的工具不做的程度：

- **按章节切成卡片**：按 `##` 把长文档切成带编号的卡片，2000 行手册打开是 8 张卡，可以直接跳到第三节
- **表格可用**：点表头排序、数值列右对齐、一键出柱状图、复制为 CSV
- **双击即开**：注册 `.md` 默认程序后，双击文件直接出窗口，不需要工作区、不需要建库

完整对比表见 [COMPARISON.md](COMPARISON.md)。

### 2. 为什么不直接做成 VS Code / Obsidian 插件？

三个原因，按重要性排序：

1. **目标用户不装 VS Code**。看运维手册、客户文档、群里的 README 的人，很多是运维、实施、产品，他们机器上没有编辑器。
2. **插件仍然要开编辑器**。插件的启动链路是"启动编辑器 → 加载工作区 → 加载插件 → 打开预览"，和"双击出窗口"是两个量级的等待。
3. **文件关联做不到**。插件无法把 `.md` 的默认打开程序改成自己，而"双击就开"是这个工具的核心体验。

### 3. 能不能编辑？

不能。**这是设计选择，不是没做完。**

一旦加入编辑，就要处理撤销栈、自动保存、冲突合并、只读文件、大文件 diff——这些会把它变成另一个 VS Code，而它存在的理由恰恰是"不做那些事"。

要编辑请用 Typora / Obsidian / VS Code。改完保存，MD Reader 里按 `Ctrl + R` 或重新打开就会读到新内容。

## 二、性能与体积

### 4. 一个 3.8 MB 的 HTML，打开不慢吗？

不慢。本地文件没有网络请求，冷启动实测约 **0.4–0.8 秒**（受磁盘和机器影响）。

体积主要来自三个内嵌库：

| 组成 | 体积 |
|---|---|
| mermaid（流程图） | ≈ 3.2 MB |
| highlight.js（代码高亮，40+ 语言） | ≈ 0.4 MB |
| marked（Markdown 解析） | ≈ 0.05 MB |
| 应用代码 + 图标 + 二维码 | ≈ 0.15 MB |

**如果不需要流程图，理论上可以砍到 0.6 MB 左右。** 目前没有做这个精简版，因为"文档里有流程图"和"文档里只有代码块"在排查手册这类场景里是完全不同的可读性。

### 5. 为什么 Windows 安装包有 100 多 MB？

因为安装版用的是 Electron，它自带一整个 Chromium 运行时（约 100 MB）+ Node.js。

三个版本的体积差异就是这个原因：

| 版本 | 体积 | 为什么 |
|---|---|---|
| 便携版 | ≈ 1.3 MB | 就是那个 HTML 文件 + 启动 bat，用系统自带浏览器内核 |
| 免安装桌面版 | ≈ 153 MB | Electron 运行时，解压即用 |
| 安装版（NSIS） | ≈ 117 MB | 同上，压缩过 |

**只想看文档的话，用便携版就够了，功能完全一样。** 装桌面版是为了拿到"桌面图标 + `.md` 默认关联 + 单实例"。

## 三、隐私与网络

### 6. 真的完全不联网？我怎么自己验证？

真的。而且这个承诺是**可以自己验证的**，不需要信我。

在仓库根目录执行：

```bash
# 1. 运行时代码里是否有任何对外请求
grep -nE "fetch\(|XMLHttpRequest" MDReader/src/app.js MDReader/src/template.html MDReader/src/mermaid-flow.js MDReader/src/text-flow.js

# 2. 是否有外部域名引用（排除 SVG 命名空间这类无害字符串）
grep -nE "https?://[a-zA-Z0-9.-]+" MDReader/src/app.js | grep -vE "w3\.org|xmlns"

# 3. 最硬的验证：断网后打开
#    拔网线 / 关 Wi-Fi，双击 MDReader.html，功能应完全正常
```

前两条命令在干净仓库里都应该只返回空或极少数无关命中。第三条是终极验证——**断网还能用，才叫离线**。

### 7. 我的文档会被上传吗？

不会。文档只在本机浏览器（便携版）或 Electron 渲染进程（桌面版）内解析，没有任何上传路径——因为代码里没有发请求的能力（见上一题）。

### 8. 数据存在哪？多台机器会同步吗？

**不会同步。** 没有账号系统，也没有云。

| 数据 | 存储位置 |
|---|---|
| 最近打开列表、主题/皮肤偏好 | 便携版：浏览器 `localStorage`；桌面版：`%APPDATA%\mdreader` |
| 文档本身 | 原地不动，只读不写 |
| 便携版的 `_autoload.js` | 与 bat 同目录（仅用于注入初始文件路径，卸载时随目录一起删） |

桌面版卸载后 `%APPDATA%\mdreader` 可能残留偏好设置，手动删除即可，不影响系统。

## 四、兼容与能力边界

### 9. 支持哪些 Markdown 语法？哪些不支持？

**支持**：GFM 表格、标题、有序/无序/任务列表、引用、分割线、粗斜体、删除线、行内代码、链接、图片、40+ 语言代码高亮、`> [!note]` 类 Callout、YAML frontmatter 属性表、`#标签` 高亮。

**Obsidian 专有语法**：`[[双链]]`、`![[图片]]` 嵌入支持显示（点击双链不会跳转，因为本工具不知道你的库结构）。

**不支持**：脚注 `[^1]`、数学公式（KaTeX/MathJax）、目录 `[TOC]`、HTML 内联块的部分标签、编辑。

> 数学公式是明确的缺口。如果你主要看带公式的文档，这个工具目前不适合你。

### 10. 流程图为什么有的能跟随深色主题，有的不能？

因为流程图有两套渲染路径：

| 路径 | 触发条件 | 主题跟随 |
|---|---|---|
| 自研渲染器（MD FLOW） | 常见流程图语法（6 种形状 + 4 种箭头） | ✅ 完全跟随，还有连线流动动画 |
| 官方 Mermaid | 命中 `subgraph` / `gantt` / `sequenceDiagram` / `classDiagram` 等 18 类进阶语法 | ❌ 使用官方默认配色 |

这是**有意的降级设计**：进阶语法交回官方实现保证正确性，常见语法走自研渲染器换取主题一致性。原理详见技术文章《我没重写 Mermaid，只在它前面加了一道判定》。

### 11. 文件编码有要求吗？打开是乱码怎么办？

自动识别 **UTF-8** 与 **GB18030**（兼容 GBK / GB2312）。标题栏右侧会显示当前识别的编码。

如果仍然乱码：

1. 确认文件不是 UTF-16 或带 BOM 的异常编码
2. 用编辑器另存为 UTF-8 再打开
3. 提一个 Issue，附上文件前 100 字节的十六进制（`xxd -l 100 文件名`）

### 12. 文档里引用的相对路径图片显示不出来？

MD Reader 会按"文档所在目录"解析相对路径。以下情况会失败：

- 文档是**拖进来的单文件**，但图片在磁盘的另一个目录（浏览器安全策略不允许跨目录读取）
- 文档通过**局域网 URL** 打开（PWA 场景），图片路径指向了服务器上不存在的位置

解决办法：用「打开文件夹」而不是「打开文件」，让工具知道完整目录结构。

## 五、平台

### 13. macOS 能用吗？

**能用，但需要你自己编译。** 构建配置（`electron-builder` 的 mac target）已经写好，但作者手上没有 Mac，没实测过 `.dmg`。

如果你编译成功了，欢迎提 PR 补充 `docs/PLATFORM.md` 的实测结论。

### 14. iOS 版为什么不能设成默认打开方式？

iOS 系统不允许第三方应用注册全局文件类型默认程序（只有部分类型通过"共享表单"接收）。这是平台限制，不是没做。

iOS 版的实际用法是：Safari 打开 → 分享 → 添加到主屏幕 → 当成一个 App 用，在里面点「打开文件」从「文件」App 里选 `.md`。

### 15. 能打印 / 导出 PDF 吗？

能。`Ctrl + P` 走系统打印，可选"另存为 PDF"。打印时侧栏、工具栏、卡片装饰会自动隐藏，只输出正文——这是专门调过的，不是默认行为。

也可以「导出独立 HTML」：样式和图片全部内嵌，发给别人双击就能看，不依赖任何外部文件。

## 六、贡献与许可

### 16. 我可以商用 / 改了自己发吗？

可以。MIT 协议，允许商用、修改、再分发，只需保留版权声明与许可声明。

如果你改了并发布，**不必**回馈代码，但欢迎提 PR——尤其是平台适配和语法支持这类。

### 17. 提 Issue 前请先做三件事

1. 在本文里搜一下关键词（80% 的问题这里都有）
2. 确认用的是最新版本（`docs/screenshots/` 里的界面如果和你看到的不一样，可能是旧版）
3. 附上：系统版本、用的哪个版本（便携 / 安装 / iOS）、复现步骤、以及**一份能复现的最小 `.md` 文件**

第 3 条最重要。没有可复现文件的问题，基本无法定位。
