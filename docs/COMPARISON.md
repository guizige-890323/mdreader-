# 同类工具对比

> 最后更新：2026-11 · 对比基于各工具公开文档与作者实际使用体验。**如果这里的信息过时或有误，欢迎提 PR 修正**——这份表的价值在于准确，不在于让 MD Reader 赢。

先说结论：**写长文不要用 MD Reader。** 它以阅读为主，编辑只做到"够改一行"的程度，不是主力写作工具。这份对比的目的不是证明它更好，而是帮你判断"我到底需要哪一个"。

## 二、四个关键维度的展开

### 1. 「打开一份文档」需要几步

这是 MD Reader 存在的唯一理由，所以单独说。

| 工具 | 从"想看一眼"到"看到内容"的路径 |
|---|---|
| **MD Reader** | 双击文件 → 出窗口（1 步） |
| Typora | 双击文件 → 出窗口（1 步）**——但在编辑态** |
| Obsidian | 打开 Obsidian → 等库加载 → 在库里找到这篇 → 打开（3–4 步，且可能触发索引） |
| VS Code | 打开 VS Code → 等工作区恢复 → 打开文件（3 步，首次更慢） |
| 在线编辑器 | 打开浏览器 → 打开网站 → 上传文件 → 等渲染（4 步，且文档已出网） |

**Typora 在"1 步"这一项上和 MD Reader 打平**，这是它很强的地方。区别在于：Typora 打开就进入编辑态，MD Reader 打开是阅读态（要点「编辑」才进编辑）。如果你经常担心误触改了别人的文档，这个区别有意义。

### 2. 长文档的浏览方式

2000 行的排查手册，四种工具的呈现：

| 工具 | 呈现 |
|---|---|
| MD Reader | 按 `##` 切成 N 张卡片，每张带 `01`/`02` 编号和字数，可点编号跳转；也可切「纸张」皮肤变连续长文 |
| 其他 | 连续滚动，靠大纲面板（如果有）跳转 |

这不是"更好"，是**不同**：卡片适合"我要找第三节"，连续适合"我要通读"。所以 MD Reader 两套皮肤都做了。

### 3. 表格

Markdown 表格在多数阅读器里是"能显示但不智能"的：宽表溢出、数字左对齐、不能排序。

MD Reader 做了四件事：斑马纹 + 悬停高亮 + 表头固定、点表头排序、数值列自动右对齐、一键柱状图 + 复制为 CSV/TSV。

Obsidian 和 VS Code 要靠插件才能接近这个体验，Typora 和 MarkText 基本不做这块。

### 4. 隐私

这一项没有中间态：

| 类别 | 工具 | 文档是否可能离开本机 |
|---|---|---|
| 本地 | MD Reader、Typora、Obsidian、MarkText、VS Code | 不会（除非你主动同步） |
| 在线 | 各类在线编辑器 | **会**，至少要上传到渲染服务端 |

如果你的文档里有内网 IP、账号字段、客户信息，**在线编辑器这一栏可以直接排除**，不是"要注意"，是不该用。

## 三、什么时候该选别人（重要）

| 你的需求 | 该选 | 为什么 |
|---|---|---|
| 我要写文档 | **Typora** | 所见即所得做得最好，写作体验是这个品类的标杆 |
| 我要管理 1000+ 篇笔记、要双链和图谱 | **Obsidian** | 知识库能力是它的核心，MD Reader 只做了"显示"那一层 |
| 我要边写代码边看 README | **VS Code** | 你本来就在里面，多装一个工具是负担 |
| 我要免费开源、要能改 | **MarkText** 或 **MD Reader** | 两个都 MIT；要编辑选前者，要阅读选后者 |
| 我要多人协作、云同步 | **飞书文档 / 语雀 / Notion** | MD Reader 明确不做账号和同步 |
| 我要看带数学公式的文档 | 换别的 | **MD Reader 不支持 KaTeX / MathJax，这是硬缺口** |
| 我在 Mac 上，不想自己编译 | 换别的 | macOS 构建配置就绪但未实测，不推荐当主力 |

## 四、MD Reader 明确不做的三件事

写在对比表里不如单独说清楚，免得你装了才发现：

1. **不做全功能编辑器。** 编辑只做到"按块改几行 + 写回原文件"，不做语法高亮编辑、多光标、插件、Vim 模式、Git 集成。做到那个程度它会变成另一个 VS Code，而它存在的理由是不做那些。
2. **不做知识库。** 不索引、不建图谱、不做全文跨文档搜索。`[[双链]]` 只显示不跳转，因为它不知道你的库结构。
3. **不做账号与同步。** 没有登录、没有云端、没有多端同步。你的文档只有一份，在你自己的磁盘上。

如果你的需求里有一条落在上面，**这个工具不适合你**——这不是谦虚，是它真的没做。

         │                                        │
    Typora ●                                     │
   MarkText ●                                    │
        Obsidian ●                               │
     VS Code ●                                   │
                                    ● MD Reader
