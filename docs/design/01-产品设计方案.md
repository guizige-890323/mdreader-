## 1. 产品概述

### 1.1 一句话定位

**零安装、零联网、零上传的本地 Markdown 阅读与轻编辑工具**——把 `.md` 文件变成"一页安静、精致、可交互的文档"，全程离线，敏感笔记也放心读。

### 1.2 产品愿景

> 好的工具应该让人忘记工具本身，只看见内容。

Markdown 是技术写作与 AI 输出的事实标准格式，但"写"的工具很多，"读"的體驗长期缺位：终端里表格错位、聊天窗口里流程图是一堆 `graph LR A-->B` 字面文本、编辑器预览排版粗糙。MD Reader 补齐"渲染阅读"这一步，并向 AI 时代延伸——通过 MDLens 渲染管道，让任何 AI/Agent 的输出都能变成人真正想读的页面。

### 1.3 产品形态矩阵（现状）

| 形态 | 载体 | 状态 | 说明 |
|---|---|---|---|
| 网页单文件版 | `dist/MDReader.html`（约 4.4 MB） | ✅ 已交付 | 双击即用，完全离线，含全部 vendor 与品牌资源 base64 内嵌 |
| 国际版单文件 | `dist-intl/MDReader.html` | ✅ 已交付 | 默认英文（`MDREADER_EDITION=global` 构建） |
| Windows 安装版 | NSIS `MD Reader Setup.exe` | ✅ 已交付 | 桌面/开始菜单快捷方式 + `.md/.markdown/.mdown/.mkd` 四扩展名关联（HKCU，免管理员） |
| Windows 便携版 | 免安装 zip | ✅ 已交付 | 解压即用 |
| macOS 安装版 | DMG（构建链已备好） | ✅ 同源可构建 | `CFBundleDocumentTypes` 关联，macOS 11+ |
| iOS/iPadOS PWA | `ios/site` + SW 缓存 v22 | ✅ 已交付 | 主屏幕图标 + 离线缓存；**如实声明**：iOS 不允许第三方注册默认打开程序 |
| AI 渲染管道 MDLens | CLI / HTTP / MCP Server 三接入 | ✅ v0.2.0 | `mdlens` npm 包，复用同一渲染引擎 |

| 来源 | 说明 |

## 3. 核心用户画像

### 3.1 Persona A：技术知识管理者（主力画像）

| 维度 | 描述 |
|---|---|
| 原型 | 桂子哥，昆明，通信行业技术管理岗 |
| 环境 | Windows 11 + 麒麟 V10 双环境；Obsidian 知识库 1110+ 文件，MOC 索引 + Wiki 链接组织 |
| 行为 | 每天阅读大量技术文档/方案/AI 生成报告；写作少、阅读多；对排版品质与隐私极度敏感 |

| 痛点 | 编辑器预览丑、在线工具不敢用、AI 报告表格错位 |
| 关键场景 | 双击 `.md` → 纸张模式连续阅读 → 表格切玫瑰图 → 专注模式细读 → 导出 Word 汇报 |
| 成功指标 | 打开到可读 < 1s；全程零网络请求；偏好跨会话记住 |

### 3.2 Persona B：AI 重度使用者 / Agent 开发者

| 维度 | 描述 |
|---|---|
| 原型 | 使用 WorkBuddy / Claude Desktop 的工程师与内容创作者 |
| 行为 | 每天让 AI 产出长篇 Markdown 报告；在聊天窗口里读表格和流程图非常痛苦 |
| 目标 | AI 输出自动变成精致页面；Agent 能自主调用渲染，无需人工搬运 |
| 关键场景 | Agent 调 MCP `render_markdown` → `open_preview` 实时预览 → `export_html` 交付；或 `cat report.md \| mdlens render -` |
| 成功指标 | 渲染管道零配置接入；SSE 实时刷新；导出自包含 HTML |

### 3.3 Persona C：学生 / 轻写作者

| 维度 | 描述 |
|---|---|
| 原型 | 大学生、公众号作者（如「晨曦AI研习」运营场景） |
| 行为 | 用 Markdown 记笔记/写稿；需要把 AI 初稿粘贴进来快速成文 |
| 目标 | 免费、免安装、粘贴即渲染、能导出交作业/交稿 |
| 关键场景 | 打开单文件版 → 剪贴板浮层 Ctrl+V 粘贴 AI 输出 → 按块编辑润色 → Ctrl+S 另存 → 导出 PDF |
| 成功指标 | 零学习成本；粘贴到成文 < 3 分钟 |

### 3.4 画像优先级

A（阅读体验与隐私）> B（AI 管道）> C（轻创作）。资源冲突时优先保 A 的"零联网零上传"红线与阅读性能。

## 4. 产品定位与竞争策略

### 4.1 定位声明

> 对于**需要高质量阅读本地 Markdown 的技术用户与 AI 使用者**，MD Reader 是一款**离线单文件阅读与轻编辑工具**，它提供**出版级排版、数据可视化与 AI 渲染管道**；不同于 Typora / VS Code / 在线转换站，我们**不联网、不上传、不收费、打开即读**。

### 4.2 竞品对照

| 维度 | MD Reader | Typora | VS Code 预览 | 在线转换站 |
|---|---|---|---|---|
| 离线/隐私 | ✅ 零网络请求 | ✅ | ✅ | ❌ 上传服务器 |
| 价格 | 免费开源（MIT） | 收费 | 免费 | 免费/广告 |
| 阅读排版 | 双皮肤+三主题+柔光+行高四档 | 单主题为主 | 工程风 | 简陋 |
| 表格→图表 | ✅ 6 型智能选型 | ❌ | ❌ | 部分 |
| 文本/ASCII 流程图转图形 | ✅ 纯算法 | ❌ | ❌ | ❌ |
| 专注阅读 | ✅ 图标极简菜单 | 禅模式 | ❌ | ❌ |
| AI/Agent 接入 | ✅ MCP/CLI/HTTP | ❌ | ❌ | ❌ |
| 轻编辑 | ✅ 按块编辑 | ✅ 强 | ✅ 强 | ❌ |

**策略**：不与重型编辑器拼写作能力，守住"阅读体验 + 隐私 + AI 管道"三个差异化支点。

### 4.3 产品红线（不可妥协项）

1. **零联网**：运行时不发起任何网络请求（vendor/字体/图片全内嵌）。
2. **零上传**：文档内容永不离开本机；MDLens HTTP 服务仅绑定本机回环。
3. **零遥测**：不采集任何使用数据。
4. **免管理员**：Windows 关联写 HKCU，不要求提权。
5. **能力如实声明**：iOS 不做"默认打开程序"的虚假承诺（见 `docs/PLATFORM.md`）。

## 6. 用户旅程地图

### 6.1 旅程一：技术用户深度阅读（Persona A 主旅程）

| 阶段 | 触点 | 用户行为 | 情绪 | 痛点/机会 | 产品支撑 |
|---|---|---|---|---|---|
| 进入 | 资源管理器双击 `.md` | 期待秒开 | 😐→😊 | 冷启动慢会流失 | 单实例锁 + pendingFiles 转发，窗口加载完即渲染 |
| 首读 | 卡片皮肤 + 文档属性卡 | 扫标题/属性 | 😊 | 长文压迫感 | 自动分节卡片 + 字数统计 + 大纲 |
| 深读 | Ctrl+O 专注模式 | 隐去一切干扰 | 😌 | 工具墙反而干扰 | CR-08：40px 图标窄轨，悬停才展开，一键收成一颗钮 |
| 看数据 | 表格右上图表钮 | 切 rose/trend | 🤩 | 表格看不出趋势 | auto 智能选型 + 6 型手动切换 + 百分比标注 |
| 看流程 | Mermaid/文本流程图 | 拖拽调整节点 | 🤩 | 源码不可读 | MDFlow 图形化 + 编辑态持久化（content/pos 双 hash） |
| 带走 | 顶栏导出 Word/PDF | 汇报交付 | 😊 | 导出后样式丢失 | 导出链 clone 当前 DOM，导出即最后编辑状态 |
| 回访 | Ctrl+R 最近打开 | 接力上次位置 | 😌 | 重读找位置烦 | 滚动位置记忆 + 偏好全量持久化 |

### 6.2 旅程二：AI 输出渲染（Persona B）

```
Agent 产出 md ──► MCP render_markdown ──► 自包含 HTML ──► open_preview（SSE 实时刷新）
      │                                                      │
      └── CLI: cat x.md | mdlens render - ──► export_html ◄──┘ ──► 人类阅读/交付
```

| 阶段 | 关键体验 | 验收口径 |
|---|---|---|
| 接入 | 零配置：MCP 客户端加一行 server 配置即可 | `mdlens doctor` 全绿 |
| 渲染 | 表格配色/代码高亮/流程图图形化一次到位 | 与网页版同一引擎，视觉一致 |
| 迭代 | Agent 改稿 → `update_preview` → 浏览器 SSE 自动刷新 | 无需手动刷新 |
| 交付 | `export_html` 单文件，离线可开 | 断网打开无外部请求 |

### 6.3 旅程三：学生粘贴成文（Persona C）

欢迎屏 → 「粘贴创建」浮层（光标自动就位，Ctrl+V 一次按键）→ 渲染 → Ctrl+E 按块润色 → Ctrl+S 另存 → 导出 PDF。全程无需理解文件系统路径；便携版剪贴板 API 不可用时自动降级为浮层输入框通道（不浪费用户授权动作）。

## 7. 交互设计规范

### 7.1 布局规范

| 项 | 规范 | 依据 |
|---|---|---|
| 工作台骨架 | 顶栏（工具）+ 左侧栏（文件/大纲/搜索/最近四 Tab）+ 标签栏 + 正文区 + 状态栏 | template.html |
| 专注模式 | 顶栏/侧栏/标签栏全隐；左侧浮动渲染菜单；右上「退出专注 · Esc」 | CR-03/08 |
| 专注菜单三态 | 收起 40px 纯图标 / 悬停展开 132px 图标+文字 / pin 极简一颗钮；窄屏（≤900px）36/116px | CR-08 实测 |
| 正文让位 | 收起 112px；展开 170px（菜单右缘 146 + **24px 呼吸位**）；窄屏 62/142px | CR-08 |
| 菜单分组 | 排版→字号→行高→开关→主题五组，组间 19px 空行、组内 3px，恒一列 | CR-08 |
| Toast | 底部居中，bottom 44px，不打断阅读 | test-focus-render |

### 7.2 快捷键规范（全局唯一注册点）

| 操作 | 快捷键 | 备注 |
|---|---|---|
| 打开文件 | `Ctrl+Shift+O` | 支持多选；避让浏览器 Ctrl+O |
| 专注模式 | `Ctrl+O` | 再按退出 |
| 退出专注 | `Esc` | |
| 最近打开 | `Ctrl+R` | 接力回上次位置 |
| 收起/展开侧栏 | `Ctrl+B` | |
| 编辑源码 | `Ctrl+E` | 按块/整篇切换 |
| 保存 | `Ctrl+S` | 保真换行与 frontmatter |
| 查找 | `Ctrl+F` | 高亮命中逐条跳转 |
| 上/下一块 | `Alt+↑ / Alt+↓` | 编辑模式 |

**规则**：macOS 以 `Cmd` 等价替换；快捷键不得与浏览器默认语义冲突（历史教训：原 Ctrl+O 打开文件与浏览器抢键，CR-03 顺延为 Ctrl+Shift+O）。

### 7.3 状态同步规范（CR-08 确立的强制口径）

1. **单一数据源**：每个设置只有一个权威状态（`S.*` + DOM 原控件），所有 UI（顶栏/设置面板/专注菜单/导出页菜单）都是它的投影。
2. **汇聚点闭环**：任何 setter（`setTheme` / `applyLayout` / `syncToggles` / `setLineHeight`…）在更新数据源后**必须**调用 `syncFocusRender()` 回读，双向同步，不允许"碰巧正确"的路径。
3. **图标态可访问性**：纯图标按钮必须带 `title` + `aria-label`（含名称）+ `aria-pressed`；文字层保留在 DOM（`max-width:0;opacity:0`）供读屏与 i18n。
4. **动效**：宽度切换瞬时完成（不做 CSS 过渡，避免胶囊量到中间值），文字 opacity .16s 淡入；`prefers-reduced-motion` 下全部降级为无动画。

### 7.4 视觉规范

| 项 | 规范 |
|---|---|
| 主题 | 浅色/深色/护眼三套 CSS 变量；所有组件（含专注菜单、胶囊、图表）走 `--panel/--border/--accent` 变量，禁止硬编码色值 |
| 云晰柔光 | 全应用统一暖色板重映射（sepia/sat/con/bri/noise 五参数），菜单/顶栏/侧栏同源 |
| 胶囊高亮 | 液态胶囊（LP）跟随选中项平移拉伸；多选宿主保留兜底底色；对比度 ≥ 4.5:1（test-cr06 强制） |
| 图标 | 极简符号图标（▥ ▭ A− A+ ≡ ☰ ╤ ╳ ◐ ◔ ⇄ ☀ ☾ ◉），无语言依赖，中英界面完全一致 |
| 品牌 | 两组 LOGO（minimal/cartoon）× 明暗两版；深色下海报经 CSS filter 自动反转 |

### 7.5 反馈与容错规范

- 一切状态变更给 toast（i18n 覆盖）；破坏性操作（关闭未保存标签/返回预览）必须二次确认。
- 剪贴板权限失败 → 自动降级浮层 Ctrl+V 通道，文案明示"只需一次按键"。
- 空文档/空文件夹给引导文案而非空白。
- 打印/PDF 媒体下隐藏全部工具元素（菜单、胶囊、toast）。
