## 双击就能看 `.md` 的那个小软件

4.6 MB 单文件，零联网，不登录，不收集任何数据。

这次更新源于一句很具体的话：**「图表的颜色为什么要跟着表格走？」**

---

### 这一版变了什么

**每张流程图可以有自己的结构**
流程图右上角多了三个按钮（自动 / 纵向 / 横向）。以前改一次结构，全文所有图一起变；现在只影响你点的那一张，且会被记住。同一篇文档里，「部署流程」用横向、「告警链路」用纵向，互不干扰。

**颜色从「贴纸」变成「风格」**
原来图表配色绑在表格上，选个表格样式，图表也跟着换色——很别扭。现在提升为整篇文档的统一风格：**黑白极简 / 蓝色科技 / 红色政商 / 粉色卡通**。分段背景、卡片徽章、六种图表、流程图强调色、代码关键字，一次性整体协调。导出的 HTML 也会带上这套风格，离线打开和屏幕上一致。

**Unicode 框线图，直接变成可编辑的流程图**
把这种图粘进来：

```
┌──────────────┐
│  网络设备     │
└──────┬───────┘
       │ UDP 5140
┌──────▼───────┐
│  采集服务     │
└──────────────┘
```

它会变成真正可拖拽、可改文字、可导出的矢量流程图。**纯代码算法识别，不调 AI、不联网、不上传。** 中英混排的列宽错位、手绘图的边界漂移、框内 `key=value` 和 `→` 箭头，都做了专门处理。

**其它**
- 界面支持中文 / English / 跟随系统
- 五种导出：HTML / Word / PDF / SVG / 复制源码，导出的都是你最后编辑的状态
- 首次打开有欢迎屏，卡片式浏览全部功能

### 关于下载

**预编译包暂未开放。** 这一版先开源代码，安装包会另行发布。

想现在就用，两条路都很快：

```bash
git clone https://github.com/guizige-890323/mdreader-.git
cd "mdreader-/MDReader"
python src/build.py
```

只依赖 Python 标准库，不需要 `pip install`。构建约 3 秒。

产物是 `MDReader/dist/MDReader.html`，双击即可，无需安装、无需联网。

---

### 它是什么，不是什么

**是**：一个能双击打开 `.md` 的阅读器。带目录、多标签、最近打开、代码高亮、六种图表、可编辑流程图、五种导出。

**不是**：不是编辑器（虽然能改一行字）、不是笔记软件、没有账号、没有同步、没有云、没有遥测、没有 AI 摘要。**这些是设计决定，不是没做完。**

同类产品大多是 100 MB 级的 Electron 应用或需要部署的 Web 服务。这个 4.6 MB，放 U 盘里，在没网的机器上也能打开。
