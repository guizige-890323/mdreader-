## 正文

上周三下午，运维同事在群里发来一份文档：《采集异常排查手册.md》，2000 多行。

我要找的只是第三节的一张参数表。

然后我试了三条路，每条都堵。

**第一条**，打开 VS Code。等它把上一次的工作区加载完，再等 Markdown 预览插件起来。我不是要改代码，我只是想看一张表。

**第二条**，丢进在线 Markdown 编辑器。文档里有内网 IP、有采集节点的账号字段。合规上过不去，我自己也不放心。

**第三条**，系统自带的预览。双击打开，一整页黑字，从第一行开始滚。滚到第三十屏，我已经忘了要找什么。

那天晚上我做了个东西，解决问题只需要一句话：

**双击 `.md`，它就在一个独立的窗口里打开，不联网，不装依赖。**

后来它慢慢长成了现在这样——我把源码开源了。

### 先说清楚它不解决什么

这一节可能比功能列表更重要。

**它不是主力编辑器。** 它能改字、能保存（按块修改，`Ctrl+S` 写回原文件），但没有语法高亮编辑、没有多光标、没有插件。写长文还是回 Typora / Obsidian / VS Code；它管的是"看完顺手改一行，不想为这一行开 IDE"。

**它不是知识库。** 它不会帮你建双链图谱、不会做关系视图。它只是把 Obsidian 的 `[[双链]]`、`![[图片]]`、`> [!note]` 这些语法**正确显示出来**，让你不用为了看一篇笔记去开整个 Obsidian。

**它不是云文档。** 没有账号、没有同步、没有协作。这是设计选择，不是没做完。

把边界说在前面，你才知道它值不值得装。

### 我真正在用的三个场景

**场景一：看别人的文档，不想留痕迹。**

同事发来的手册、客户给的接口说明、从群里下载的 README。这类文档我一年要看几百份，一份都不会改。

以前的做法是"打开 IDE → 看 → 关掉"，IDE 里留下十几个临时工作区。现在双击，看完关窗口，什么都不留。

**场景二：文档里有宽表，我要看趋势不是看数字。**

排查手册里最常见的是这种表：十几个采集节点，五列指标。

普通的预览器只能给你一张静态表，你还得自己心算哪台机器的失败率高。这个里面点一下表头可以排序，点"图表"直接把数值列画成柱状图，也能一键复制成 CSV 拿去 Excel 里继续折腾。

〔配图 3：表格排序 + 柱状图，用 `01-card-light.png` 局部裁切或补拍〕

**场景三：一份手册 8 个章节，我需要"跳"而不是"滚"。**

这是我个人最离不开的一个设计。

它有一个「卡片」皮肤：按文档里的 `##` 二级标题自动切块，每一块是一张独立卡片，左上角有 `01`、`02` 编号和字数。2000 行的手册打开是 8 张卡，我要看第三节就直接点第三张。

还有一个「纸张」皮肤：换成正文字体、暖米色纸面、页边装订线，适合长文阅读和打印。

两套皮肤不是换个边框，配色、字体、圆角、投影、表格和代码块的样式都是整套切换的。

### 为什么是"一个文件"

这是它和其他 Markdown 工具最不一样的地方，值得单独说。

整个程序就是**一个 3.8 MB 的 HTML 文件**。所有依赖（Markdown 解析、代码高亮、流程图渲染）都打包在里面，**运行时不会向任何服务器发请求**。

这意味着几件事：

- 拷到 U 盘，插到一台**完全断网**的机器上，双击就能用
- 内网机器、隔离环境、客户的演示机，都不用走审批装软件
- 你的文档从头到尾没有被上传过——这句话不是承诺，是可以自己验证的：代码里没有任何一处向外发请求
- 三年后这个项目没人维护了，你手里那个 HTML 文件照样能打开

〔排版提示：这一段建议用引用块 + 加粗前两句〕

如果你想要更"正式"的形态，还有两个：

| 形态 | 适合 |
|---|---|
| **便携版**（解压即用） | U 盘、临时机器、内网离线 |
| **Windows 安装版** | 日常主力机。装完能直接把 `.md` 设成默认用它打开 |
| **iOS 主屏幕版** | 在 iPhone / iPad 上看 md，像 App 一样全屏启动 |

三种形态用的是**同一份 HTML**，渲染能力完全一致，不存在"精简版"。

### 怎么开始用（不到 1 分钟）

**最快的方式**：去 GitHub 仓库下载便携版压缩包，解压到一个文件夹，双击里面的「启动 MDReader.bat」。

就这样。没有安装向导、没有账号、没有首启配置。

想让它接管双击：右键任意 `.md` → 打开方式 → 选择其他应用 → 找到那个 bat（或装了安装版就直接选 MD Reader）→ 勾上"始终使用此应用"。

**项目地址**：`github.com/guizige-890323/mdreader`

### 适合谁，不适合谁

**适合**：

- 经常收到 `.md` 文档，只想看不想改的人
- 内网 / 隔离环境，不能随便装软件的人
- Obsidian 用户，想快速预览单篇笔记，不想开整个库的人
- 需要把文档打印或转 PDF 的人

**不适合**：

- 需要编辑 Markdown 的人（请用 Typora / Obsidian / VS Code）
- 需要多人协作、云同步的人（请用飞书文档 / 语雀 / Notion）
- 需要知识图谱、双向链接分析的人（请用 Obsidian / Logseq）

同类工具里它不是最强的，只是在"**双击看一份本地文档**"这件事上，它可能是最省事的。
