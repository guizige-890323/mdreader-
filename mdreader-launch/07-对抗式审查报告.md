## 一、拆解：发布链条只有四个环节，每个都可能断

```
陌生读者 ──① 看见 ──> 点进仓库 ──② 相信 ──> 下载 ──③ 装得上 ──> 用起来 ──④ 留下来
```

我按这四环逐个做"破坏测试"：主动假设每一环都会失败，再去找证据。

| 环节 | 假设它会怎么断 | 实测结论 |
| --- | --- | --- |
| ① 看见 | 文章发了但下载入口是死的 | 关键词回复话术已有，但**发布包不存在**（P0-5） |
| ② 相信 | README 写的文件和实际对不上 | 文件名少版本号、体积数字过期（P1-1、P1-3） |
| ③ 装得上 | 解压后没有启动器 | **四个启动相关文件全缺**（P0-1） |
| ④ 留下来 | 产品里让你扫一个"同名公众号" | 实际号名是「晨曦AI研习」（P0-2） |
