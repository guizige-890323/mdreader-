这不是墨水屏。柔光屏仍然是自发光面板，真正的差别在表面那层纳米蚀刻涂层——它把原本镜面反射的光打散成漫反射，所以你看到的不是一块亮板，而是一页纸。

网页无法复刻涂层，但能复刻它给人的观感结果：底色不再是刺眼纯白，文字不再是硬黑，整体对比度压下来，色彩收一点，纸面浮起一层几乎看不见的颗粒。

右上角的开关是柔光总闸。点开关本体立即开关，点旁边的文字打开调参。柔光关掉时主题色和排版完全不动，方便随时对照原生观感。判断标准只有一条：看久了眼睛不累吗？

一、三层解耦：主题、柔光、排印互不干扰

最初这三件事是揉在一起的——主题里塞了 sepia 和 contrast，于是"换主题"实际上等于"换柔光强度"，两件事没法独立调。想在墨绿纸上用轻度柔光？做不到。

现在拆成三层，任意组合：

三层职责划分
层决定什么可选值载体
主题纸与墨的颜色米黄纸 / 旧书本 / 墨绿纸 / 夜间data-theme
柔光玻璃有多柔（滤镜 + 颗粒）开 / 关，参数连续可调data-pm
排印字多大、行多宽、层级多陡连续可调CSS 变量

这才是"适用于不同主题的通用渲染效果"：柔光是一层可以盖在任何纸上的玻璃，不是某套配色的一部分。

二、为什么要绕开纯白与纯黑

普通网页的白是 #FFFFFF，在自发光面板上相当于直接对着灯看。柔光屏的纸感来自两件事：底色偏暖，以及白色不再是"最亮"。米黄纸用 #FDFBF4 —— 带一点米黄，亮度低一点点，但足够干净。

文字同理。#000000 与米色底相接时边缘对比过强，看久了发涩。改成 #1F1F1F 深炭灰，观感立刻松下来，清晰度几乎没有损失。

#FDFBF4 米黄纸
#F4ECD8 旧书本
#F2F3F0 墨绿纸
#181818 夜间

切主题时注意一件事：纸底色不参与柔光滤镜。这是刻意的——纸是物理层，涂层是光学层。早先把滤镜加在根元素上，结果 #FDFBF4 被自己的 contrast(89%) 拉成 rgb(234,234,225)，纸色从来没真正呈现过，而且对比度越低纸越脏。

三、滤镜参数的分工

整页套一层 sepia + saturate + contrast + brightness，四个参数各管一件事：

柔光滤镜参数分工与推荐区间
参数作用推荐区间过头会怎样
sepia暖化，抵消冷蓝光8%–15%偏黄，像旧羊皮纸
saturate压低色彩鲜艳度70%–80%发灰，失去生气
contrast柔光的核心85%–90%过 95% 就退回普通高清屏
brightness整体亮度微调95%–98%拉高就变刺眼

绝对不要加 blur()。柔光屏柔化的是反光，不是文字。一加模糊，方向就整个跑偏，变成劣质墨水屏模拟。

四、颗粒要"若有若无"

AG 涂层的微纹理是柔光屏的手感来源。网页上用一个 SVG 分形噪声，opacity 控制在 0.02–0.03。这个值很窄：低于 0.02 感觉不到，高于 0.04 文字开始发糊。

夜间主题要特别处理：颗粒的混合模式必须从 multiply 翻成 screen，否则深色底上会出现脏斑。这个切换跟着主题走，不需要手动调。

五、排印：标题必须压得住正文

这是长文档最容易出问题的地方。旧版把标题写死成固定 rem——h3 是 1.02rem（16.32px），正文 1.10rem（17.6px）。三级标题比正文还小，读者扫视时找不到层级，结构化阅读直接失效。

现在改用模数化字阶：正文 --pm-fs 是唯一基准，h1 / h2 / h3 全部由它乘系数得出。拖"正文字号"时整个层级等比缩放，比例永远不会塌。

字阶计算关系
层级计算公式默认值（正文 1.05rem）与正文比
H1h2 × 1.361.995rem / 31.9px1.90×
H2滑杆值（默认 1.42）1.491rem / 23.9px1.42×
H31 + (h2-1) × 0.341.143rem / 18.3px1.14×
正文--pm-fs1.05rem / 16.8px1.00×

H3 的公式刻意压低幅度：它只需要"比正文大一点点 + 加粗 + 上留白"就能被识别为标题，不需要靠字号拉开。这正是技术文档的做法——层级多了以后，字号差太大会让页面碎掉。

行长与行高

正文栏宽默认 42rem，折合单行约 65–70 个汉字。行高 1.8。这两个数字不是审美偏好，是眼球移动成本——行长太宽，读完一行回扫到下一行开头时容易串行。

段距大于行距

段间距约 1.15rem，行距约 1.9rem。段落之间留白比行间更松，读起来才有"翻段"的节奏，而不是一整块墙。

字族：四种都试一遍

面板里有宋 / 黑 / 楷 / 粗黑四档。宋体最接近纸质印刷，长文疲劳度低；黑体在屏幕上更锐利，适合技术文档；楷体笔画舒展，读散文舒服但小字号容易发虚；粗黑（SimHei）字重沉，适合标题或强对比场景。换字族不影响字号与行高——它们分属不同层。

-webkit-font-smoothing: antialiased;
text-rendering: optimizeLegibility;

让字形边缘顺滑，模拟柔光屏的字体渲染，不会发毛。

六、夜间不是黑底白字

切到夜间主题看看。底色是 #181818 深灰，文字是 #C8C6C0 暖灰——刻意避开 #000 + #FFF 的强对比。纯黑白在暗环境下会让瞳孔反复收缩，比白天更容易累。

夜间主题本身只换色。柔光强度需要单独调低：contrast 到 85%、brightness 到 92%、颗粒降到 0.020。这也是分层的好处——同一套柔光参数在深色纸上会显得过重，你可以只调柔光不动主题。

七、边界：这套方案做不到什么

能力边界
能做到做不到
弱化纯白硬反光的观感真正消除镜面反射
降低蓝光刺激、压对比替代硬件 AG 涂层
模拟纸面颗粒与暖调在强光下依旧不反光
长文阅读的舒适排版达到墨水屏的无背光体验

强光环境下，浏览器屏幕依然会反光——那是物理层的事。这套方案是软件层的视觉模拟，适合私有化阅读器、文档阅读页面。
