让 Markdown 阅读成为一种享受

📄这不是说明书，是一份可以边读边点的样例

文中的表格能排序、能出图，代码能一键复制，流程图能一键转成图形，标题自动汇成大纲。顺着读完这一篇，MD Reader 的核心能力你基本都亲手试过了。

MD Reader 是一个只有几 MB 的单文件应用：把 .md 拖进来，就得到一页安静、精致、可交互的文档。全程离线、不上传、不采集，再敏感的笔记也放心读。

💡三步开始

① Ctrl+Shift+O 打开文件（或直接把文件 / 整个文件夹拖进窗口） → ② 左侧「文件 / 大纲 / 搜索 / 最近」自由切换 → ③ 顶栏「导出」把成果带走。

先看这份清单

  • 打开单个 .md，或拖入文件夹直接建起一座整库
  • 用 A− / A+ 调字号、行高 调行距（紧凑 / 标准 / 舒适 / 宽松），顶栏换 浅色 / 深色 / 护眼 三种肤色
  • 点任意表头排序，点「复制 CSV」把数据粘进 Excel
  • 按 Ctrl+E 进入按块编辑，改完 Ctrl+S 保存
  • 点「专注」进入沉浸阅读，按 Esc 回到工作台

04

表格会说话

1.5k 字

数据表格在 MD Reader 里不是静态的：点表头排序、复制 CSV / TSV 导出、右侧四套配色换肤，点「图表」就地生成 自动 / 柱状 / 折线 / 趋势 / 环形 / 玫瑰 六种视图。五种图表都按主流可视化审美重做过：柱状带垂直渐变与顶端数值，折线是平滑曲线加空心描边圆点，趋势是渐变面积图，圆角环形图是零描边的 ECharts 式分块（圆角扇区 + 中心总量 + 右侧占比清单），南丁格尔玫瑰图在此基础上把扇区按数值从小到大顺时针排列、等角变径向外辐射，花瓣感与增长感一眼可辨。参考 ECharts 示例库里最受欢迎的几种实现。打开顶栏「图表总开关」，之后每一份文档的数据表都默认展开。

Callout 提示块全家桶

📝笔记

适合补充说明、随手记下的背景信息，不打断主线。

ℹ️信息

中性事实与口径说明，配一枚蓝色信息标。

✅成功

结论、已完成项、验证通过的结果。

❓问题

把待确认的疑问单独拎出来， review 时一眼能看到。

⚠️警告

需要留意的边界条件，比如编码、路径、导出差异。

🚨危险

不可逆操作、数据丢失风险，用最高优先级标出来。

📌示例

一段可照抄的用法，或一组演示数据。

☑️待办

下一步要做什么，和任务列表配合使用。

💬引用

金句、出处、访谈原文，与正文拉开层次。

三个典型场景

  1. 读一份季度经营分析：拖入 .md → 表格自动出图 → 切「蓝色科技」配色 → 点表头按收入排序 → 「复制 CSV」贴进 Excel → 导出 Word 交材料。
