Make Markdown reading a pleasure

          

            
            
          

          

            

              
MD 复制即创建新

              复制 AI 输出的 Markdown，悬停即成一页排好版的文档。
            

            

              
表格秒变六种图表新

              选中两列就出图：柱状 / 折线 / 趋势 / 环形 / 玫瑰，自动选型。
            

            

              
双引擎流程图新

              Mermaid、文本箭头、字符画三条入口，同落一张可拖拽编辑的图。
            

            

              
一套令牌五处同频

              换一次风格，分段背景、图表、流程图、代码高亮同时换装。
            

            

              
知识库原生双链

              [[双链]]、![[图片]]、Callout、YAML 属性开箱即渲染。
            

            

              
导出仍是活页面

              导出的 HTML 仍可点、可切图型、可复制 CSV，不是死图。
            

            

              
MCP 连接器新

              CLI / HTTP / MCP 三接入，AI 工具直接把 Markdown 渲成页面。
            

            

              
大纲与块编辑

              点标题即跳；按块编辑，保存后换行与属性分毫不差。
            

            

              
两套经典排版

              卡片分节面板 vs 纸张描图纸面，字体圆角投影整套换。
            

            

              
最近，重读磁盘

              点历史按路径重读磁盘原文，不是打开一张旧快照。
            

            

              
15 项偏好全记住

              语言、排版、字号 12–22px、皮肤、柔光、图表、流程图全记住。
            

            

              
专注模式

              隐去侧栏与工具条，只留正文与进度，渲染菜单照常可用。
            

            

              
原创云晰柔光原研

              顶栏、侧栏、阅读区、弹层统一柔化，色阶连续无贴片感。
            

            

              
爱护你的双眼

              低蓝光暖米黄 + 字号行高可调，密集表格调宽更透气。
            

            

              
国际化版本

              中文 / English / 跟随系统，长句优先；正文永不参与翻译。
