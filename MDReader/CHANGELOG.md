# MD Reader 更新日志

本项目为 Windows 11 风格 Markdown 阅读器（单文件离线 HTML + Electron 桌面版 + iOS PWA）。

## v1.3.0 (2026-11-11)

### 编辑体验（重大改进）
- **按块/段落编辑取代整篇编辑**：编辑模式不再把整篇文档塞进一个 textarea（原先会导致章节乱序、无法定位）。
  - 文档按语义切分为有序「逻辑块」：标题(H)、段落(¶)、列表(•)、表格(▦)、代码(`</>`)、引用(❝)、分隔线(―)。
  - 左栏「✎ 段落」列出每个块，带类型标签与字数；点击或上一块/下一块按钮即可选中单块编辑。
  - 块间空行作为 `gap` 元数据保留，编辑仅修改当前块 `text`，拼回时精确保留原始换行与 frontmatter。
  - 支持无标题文档（旧「按章节」方案对无线标题文档会退化为整篇，现已对任意文档生效）。
  - 提供「整篇编辑」切换，需要时仍可编全文。
  - 逻辑经 Node 纯函数回归测试 **18/18 通过**（含无标题清单、frontmatter、空行敏感、代码内井号、表格紧接、编辑后重切分等样例）。

### 连线流水动效（MD FLOW）
- 每条连线在主灰线之上叠加两层同路径虚线（2.5px 亮线 + 7px 光晕），`stroke-dasharray:11 29` 配合 `@keyframes mf-stream` 让 `stroke-dashoffset` 由 0 → -40 循环（1.6s / 圈），形成沿路径匀速推进的「流水 / 数据流」效果。
  - 周期固定 40px、与路径长度无关 ⇒ 所有边的光段像素速度天然一致，无需逐边测长。
  - 每条边 `animation-delay` 按索引错开 0.27s（6 相循环），避免整图同步闪动。
  - 流水色取**目标节点**的层级强调色（示例图：紫 → 青 → 橙），随分支向下游汇聚形成层次；三主题自动跟随。
- 交互协同：悬停节点时关联边流水加亮加粗（opacity 1 / 3.1px），非关联边整体淡出至 .12。
- **兼容处理**：
  - 动效样式内嵌在 SVG 自身 `<style>` 中 ⇒ 下载独立 SVG、导出 HTML 后动画仍在；`inlineVars()` 固化颜色后无 `var()` 残留。
  - 系统开启「减少动态效果」或打印 / PDF 时关闭流水，只留静态灰线，避免动效定格成虚线碎片（页面 CSS 与 SVG 内嵌 style 双保险）。
  - 导出 Word 时 `rasterizeFlows()` 在栅格化前先移除流水层，生成的 PNG 干净。
- 图表工具条补充「连线流水动效」说明。
- 验证：Node 回归 **48/48**、原 MDFlow CDP **21/21**、新增 `tools/verify-flow-motion.mjs` **22/22**（动画 currentTime 推进、dashoffset 逐帧变化、层级 3 色、相位 6 档、三主题、hover、导出、reduced-motion、print、连续两帧画面不同、JS 异常 0）。
