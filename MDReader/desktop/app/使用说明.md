# MD Reader · Windows 11 本地 Markdown 阅读器

**零联网、零上传。** 两种发行形态，功能完全一致，共用同一份 `MDReader.html`：

| | 便携版（本目录） | 桌面安装版 |
| --- | --- | --- |
| 安装 | 免安装，解压即用 | 双击 `MD Reader Setup 1.3.0.exe` 安装 |
| 桌面入口 | 需自己建快捷方式 | **自动创建桌面 + 开始菜单图标** |
| `.md` 关联 | 手动「打开方式」 | **安装时注册 4 种扩展名，可直接设为默认** |
| 适合 | U 盘、临时机器、内网离线 | 日常主力机器 |

## 一、快速开始

| 方式 | 操作 | 效果 |
| --- | --- | --- |
| ✅ 推荐 | 双击 `启动 MDReader.bat` | 打开独立应用窗口，再点「打开文件 / 打开文件夹」 |
| 🖥 装到桌面 | 安装 `MD Reader Setup 1.3.0.exe` | 桌面出现「MD Reader」图标，双击 `.md` 直接打开 |
| 双击关联 | 把 `.md` 拖到 `用此程序打开MD.bat` 上 | 直接打开这个文档，无需在程序里再选 |
| 最简 | 双击 `MDReader.html` | 用默认浏览器打开，功能完全一致（会有地址栏） |

程序自带 `示例文档.md`，点欢迎页的「✨ 查看示例文档」也能立即看到全部渲染效果。

## 二、功能清单

| 类别 | 支持内容 |
| --- | --- |
| 基础渲染 | GFM 表格、标题、列表、引用、分割线、粗斜体、删除线、行内代码、链接、图片 |
| **表格可视化** | 斑马纹 / 悬停高亮 / 表头固定、**点击表头排序**、数值列自动右对齐、**一键生成柱状图**、复制为 CSV / TSV |
| 代码 | 40+ 语言语法高亮（highlight.js）、语言标签、一键复制代码块 |
| 图表 | ` ```mermaid ` 流程图 / 时序图 / 甘特图等，跟随明暗主题 |
| Obsidian | `[[双链]]` 点击跳转、`![[图片]]` 嵌入、`[!note]` Callout 提示块、YAML frontmatter 属性表、`#标签` 高亮 |
| 阅读 | 左侧文件树（文件夹递归）、文档大纲、文档内查找（计数 + 前后跳转）、明 / 暗 / 羊皮纸三种配色、字号调节 |
| **排版模式** | **▥ 卡片**（浅灰画布 + 圆角白卡 + 深色编号，按 h2 分节）、**▭ 纸张**（暖米画布 + 象牙纸面 + 衬线标题 + 装订竖线） |
| **最近打开** | 自动记录打开过的文档（最多 30 条），顶栏 🕘 或 `Ctrl + R` 召唤，一键回到上次的文档 |
| 文件 | 拖拽单文件 / 整个文件夹、多文件选择、**UTF-8 / GB18030 编码自动识别**、1000+ 文件整库浏览（懒加载） |
| 输出 | 导出**独立 HTML**（样式与图片内嵌）、打印 / 另存为 PDF |

### 两种排版模式

两套模式是**完整的视觉皮肤**，不只是换个框线——配色、字体、圆角、投影、表格与代码块样式都会整体切换。

| | **▥ 卡片** | **▭ 纸张** |
| --- | --- | --- |
| 画布 | 浅灰 `#fafafa` | 暖米 `#f5f2ea` |
| 纸面 | 纯白 `#ffffff`，12px 圆角，双层柔投影 | 象牙白 `#fdfbf6`，2px 圆角，无投影 |
| 标题 | 系统无衬线（Segoe UI / 微软雅黑） | **衬线**（Iowan Old Style / Georgia / 宋体） |
| 强调色 | 蓝 `#2563eb` | 暗红 `#8c2f1e` |
| 结构 | 按 `##` 分节，每节一张小卡；左上深色编号块 `01`/`02` + 字数 | 连续长文，左侧页边装订竖线 |
| 正文行距 | 1.8 | 1.85（衬线更松） |
| 适合 | 手册 / 排查指南 / 分条目的技术文档 | 长文阅读、正式报告、打印前预览 |

顶栏下拉框随时切换，选择会被记住。卡片模式下大纲与锚点跳转照常可用（标题的 `id` 原样保留）。

### 最近打开

| 行为 | 说明 |
| --- | --- |
| 自动记录 | 每次打开文档都会记一条（文件名、完整路径、时间、字数） |
| 快速打开 | 顶栏 🕘 按钮或 `Ctrl + R`，输入文件名可筛选，点击即打开 |
| 内容新鲜度 | 点历史记录时会**按绝对路径重新读取磁盘原文**，不是显示旧快照 |
| 文件被移动 | 读不到原文时自动退回正文缓存（列表里标「仅缓存」），仍可查看 |
| 单条删除 | 悬停条目点右侧 ✕；「清空」按钮清空全部（不会删除任何文件） |

> 记录存在本机浏览器（`localStorage`），关掉程序再开仍在。上限 30 条，超出自动淘汰最旧的。

## 三、把 .md 关联成默认打开方式（可选）

### 桌面安装版（推荐）

1. 双击 `MD Reader Setup 1.3.0.exe` 安装；装完**桌面**和**开始菜单**自动出现「MD Reader」图标
2. 安装器会注册 `.md` / `.markdown` / `.mdown` / `.mkd` 四种扩展名，资源管理器里显示专用文档图标
3. 右键任意 `.md` → **打开方式** → **选择其他应用** → 选 **MD Reader** → 勾选「始终使用此应用打开 .md 文件」
4. 以后双击 `.md` 直接打开；程序已经开着时，会复用现有窗口而不是弹第二份

> 安装只需当前用户权限（写 `HKCU`，不写 `HKLM`），不用管理员、不重启。安装器会**自动备份原来的关联**，卸载时还原。
> 桌面版是单实例 + 原生文件对话框，编码识别（UTF-8 / GB18030）在主进程完成，中文文档不乱码。

### 便携版

1. 右键任意 `.md` 文件 → **打开方式** → **选择其他应用**
2. 拉到底 → **在这台电脑上查找其他应用**
3. 选中本目录下的 `用此程序打开MD.bat` → 打开
4. 以后双击 `.md` 即可直接阅读

> 该 bat 只做一件事：把目标文档内容写成本目录的 `_autoload.js`，再启动应用。不修改注册表，随时可弃用。
> `_autoload.js` 只在带 `?auto=1` 启动时生效，不影响普通启动；可以直接删除。

> **关于 macOS / iOS**：macOS 用同一份源码在 Mac 上编译出 `.dmg`，访达里 `⌘I` → 打开方式 → 「全部更改…」即可设默认。
> iOS/iPadOS **没有**系统级扩展名默认打开程序机制，只能通过「共享表单」接收文件，且每次要手动选；Electron 也不支持 iOS。详见仓库 `docs/PLATFORM.md`。

## 四、常见问题

**Q：把文件拖进窗口没反应？**（v1.2 已修复拖放稳定性，按下面顺序排查）
0. **先看右下角状态栏**：显示 `MD Reader v1.3 · 本地窗口` 才是最新版本地窗口。若还是 `v1.0` / `v1.2`，说明加载的是旧缓存 / 旧预览标签 —— 关掉重开，或重新双击 `启动 MDReader.bat`（启动器已带版本号参数防缓存）。若显示 `预览/网页环境`，看第 1 步。
1. 欢迎页顶部出现**黄色提示条** = 当前在网页 / 预览面板环境，宿主会拦截系统级拖放，请双击 `启动 MDReader.bat` 用本地应用窗口打开。
2. 拖到窗口**正文区域**再松手，出现蓝色遮罩说明事件已收到；不要松在标题栏或浏览器地址栏上。
3. 拖文件夹若 5 秒后提示「读取文件夹超时」，改用工具栏「打开文件夹」按钮（走系统选择器，最稳）。
4. 兜底：左侧文件树现有「选择 MD 文件 / 选择文件夹」两个可点按钮；也可把 `.md` 拖到 `用此程序打开MD.bat` 上，或用右键「打开方式」关联。

> **v1.3 改动**：新增卡片 / 纸张两套完整排版皮肤（配色、字体、圆角、投影整体切换）；新增「最近打开」列表（`Ctrl + R`，按绝对路径重读磁盘原文，最多 30 条）；新增桌面安装版（桌面图标 + 4 种 `.md` 扩展名关联 + 单实例）。
> **v1.2 改动**：状态栏显示版本号 + 运行环境；环境提示移到欢迎页顶部（原来在底部根本看不到）；左侧空状态新增可点击的选择按钮；窄窗口工具栏不再被裁切；启动器 URL 带版本号参数防缓存。
> **v1.1 改动**：拖放改为 capture 阶段拦截并阻止浏览器默认导航；`webkitGetAsEntry` 逐条容错、目录递归加 5 秒超时、`dataTransfer.files` 同步快照兜底；任何失败都会弹出明确提示，不再静默无反应。

**Q：为什么单独打开一个 md 时，里面的图片不显示？**
浏览器出于安全限制，不会告诉网页文件所在的磁盘目录。解决办法（任选其一）：
- 用「打开文件夹」或把文件夹拖进窗口 —— 图片会被读成内存 URL，**最可靠**；
- 用「用此程序打开MD.bat」右键打开 —— 程序知道绝对路径，能拼出图片地址；
- 把 md 和图片都放在 `MDReader.html` 同目录 —— 相对路径也能直接加载。

**Q：中文乱码？**
程序先按 UTF-8 解码，检测到替换字符会自动回退 GB18030 / GBK，并在右上角显示实际编码。

**Q：Obsidian 双链点了没反应？**
双链跳转需要目标文档也在当前已导入的文件列表里。请「打开文件夹」导入整个库，而不是只打开单个文件。找不到的链接会显示为红色虚线。

**Q：文件夹里有 1000+ 个 md，会不会卡？**
文件列表只记录句柄，点击时才读取内容，导入整库通常不到 1 秒。

**Q：桌面安装版和便携版有区别吗？**
功能完全一致，共用同一份 `MDReader.html`。桌面版多了：桌面 / 开始菜单图标、`.md` 等 4 种扩展名关联、单实例复用、原生文件对话框、主进程编码识别。代价是体积较大（含 Electron 运行时）；追求极小体积 / U 盘场景用便携版（约 2 MB，靠系统自带 Edge）。

**Q：安装要管理员权限吗？会改坏我原来的 .md 关联吗？**
不需要管理员。安装器只写当前用户 `HKCU\Software\Classes`，并**自动备份原来的关联**；卸载时还原。如果想先看看再决定，安装后在右键「打开方式」里能看到 MD Reader，但不会强制改默认 —— 需要你手动勾「始终使用此应用打开」。

**Q：SmartScreen 提示"未知发布者"？**
安装包未做代码签名（个人项目常见）。可核对 Release 里附的 SHA256，或自行加签名证书。便携版完全不触发这个提示。

**Q：需要联网吗？需要装 Python / Node 吗？**
都不需要。marked、highlight.js、mermaid 三个库已完整内嵌进 `MDReader.html`。便携版唯一要求：Windows 11 自带的 **Microsoft Edge**（用于无地址栏的应用窗口模式）；没有 Edge 时会自动退回默认浏览器，功能不受影响。桌面安装版自带运行时，连 Edge 都不需要。

**Q：数据会上传到哪里吗？**
不会。全部解析在本机浏览器 / Electron 渲染进程内完成，程序没有任何外部网络请求代码。最近打开与主题偏好只存在本机。
