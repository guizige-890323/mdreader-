## 五、本轮修掉的 3 个真缺陷

| # | 缺陷 | 后果 | 修法 |
| --- | --- | --- | --- |
| 1 | `desktop/app/` 残留的是**国际版** HTML（4.33 MB），不是国内版（4.82 MB） | 桌面版界面默认英文，与网页版不一致 | `sync-app.py` 从 `dist/` 复制；CI 加 `cmp` 断言 |
| 2 | `ios/build-pwa.py` 用 `find("<body")` 找注入点，而模板 CSS 注释里就有 `<body>` | iOS 包构建直接失败 | 取文档首个 `</head>`（真实注入点） |
| 3 | `pack-intl.py` 输出落在仓库根、无版本号 | 产物名与 README 不符，且可能被误提交 | 统一到 `发布包/` + 版本后缀 |

另有 1 处表述错误：示例文档写「五种图表都按主流可视化审美重做过」，实际是六种视图 / 五种具体图形，已改为「五种具体图表」。
