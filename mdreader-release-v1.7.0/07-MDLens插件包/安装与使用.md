# MDLens 插件包 · 安装与使用

**AI 输出 → 人类可读。** 一个给 AI 工具 / Agent 用的 Markdown 渲染管道。

> 版本：0.1.0　｜　渲染引擎基于 MD Reader v1.7　｜　协议：MIT　｜　零外部依赖（仅需 Node.js 18+）

---

## 它解决什么问题

AI 的回复是 Markdown，但堆在终端或聊天框里就是一坨：表格错位、代码块没高亮、流程图是 `graph LR A-->B` 字面文本、300 行长报告没有层级。人能读，但很痛苦。

MDLens 把 Markdown 交给本地渲染引擎，拿回一个**人真正想读的自包含 HTML**：表格有配色、代码有高亮、流程图是图形、长文自动分卡片。**不联网、不上传、不收集任何数据。**

## 一、安装（解压即用，无需 npm install）

### 前置条件

只需 **Node.js 18 或更高**。检查：

```bash
node --version
```

没有的话去 <https://nodejs.org> 装 LTS 版（装完重开终端）。

### 解压

把 `MDLens-v0.1.0.zip` 解压到一个**固定路径**（不要放临时目录，MCP 配置要写这个路径）。记住解压后的 `bin/mdlens.js` 绝对路径，例如：

```
D:\Program Files\MDLens\bin\mdlens.js
```

### 环境自检

```bash
node "D:\Program Files\MDLens\bin\mdlens.js" doctor
```

看到 `engine: OK` 就成功了。`playwright: 未安装` 是正常的——只影响截图功能，其余全部可用。

### ⚠️ 不要在这个界面配 MDLens

WorkBuddy 的「新建自定义连接器」弹窗**只支持 HTTP / SSE 远程服务**（要填 `https://...mcp` 这种 URL）。
MDLens 是**本地 stdio 进程**（`node xxx.js mcp`），没有 URL 可填，在这个界面填任何地址都会报错。

本地 MCP 要直接写配置文件（见下一节），**不是**用这个弹窗。

## 二、接入 AI 工具（MCP Server，推荐）

在客户端的 MCP 配置文件里加一段。**WorkBuddy** 配 `~/.workbuddy/mcp.json`，**Claude Desktop** 配 `claude_desktop_config.json`：

```json
{
  "mcpServers": {
    "mdlens": {
      "command": "node",
      "args": ["D:\\Program Files\\MDLens\\bin\\mdlens.js", "mcp"]
    }
  }
}
```

注意：JSON 里的路径用**双反斜杠** `\\`，或改成正斜杠 `/`。

重启客户端 → 在连接器/MCP 管理页 **信任** 这个 server → 直接对 AI 说「把这份报告渲染出来」。

**提供的 6 个工具：**

| 工具 | 用途 |
| --- | --- |
| `render_markdown` | 渲染一段 Markdown，返回可打开的文件路径 |
| `render_file` | 渲染磁盘上的 `.md` 文件 |
| `open_preview` | 开实时预览窗（长任务边写边看） |
| `update_preview` | 往预览窗推新内容，保留滚动位置 |
| `export_html` | 导出可分享 / 归档的单文件 HTML |
| `inspect_markdown` | 只分析结构不渲染，给 AI 决策依据 |

## 三、命令行（CLI，管道友好）

```bash
# 管道 —— Agent 最常用
cat report.md | node bin/mdlens.js render -

# 渲染文件（产出 file:// 单文件，双击就开）
node bin/mdlens.js render report.md

# 边改边看
node bin/mdlens.js live report.md

# 导出单文件 HTML 给同事
node bin/mdlens.js html report.md -o report.html

# 换主题 / 版式
node bin/mdlens.js render report.md --theme sepia --layout paper

# 截图（需另装 playwright-core，可选）
node bin/mdlens.js shot report.md -p chart.png --full
```

## 四、HTTP 服务（自建 UI / 编辑器插件）

```bash
node bin/mdlens.js serve        # 默认 127.0.0.1:7788
```

```bash
curl -X POST http://127.0.0.1:7788/doc \
  -H 'Content-Type: application/json' \
  -d '{"md":"# 标题\n内容","name":"demo.md"}'
# → http://127.0.0.1:7788/v/<id>   （SSE 自动刷新）
```

## 渲染能力

继承 MD Reader v1.7 的成熟管线：

- **Markdown**：GFM 全支持 —— 表格 / 任务列表 / 脚注 / 删除线
- **代码高亮**：highlight.js，180+ 语言
- **图表**：表格一键出图 —— 柱状 / 折线 / 趋势 / 环形 / 玫瑰图（默认自动展开）
- **流程图**：Mermaid 原生 + 自研文本流程图（`A → B → C` 直接变图形）
- **Callout**：`> [!NOTE]` / `[!WARNING]` / `[!TIP]`
- **主题**：light / dark / sepia　｜　**版式**：card 分节卡片 / paper 连续纸张

## 已知边界

| 项 | 说明 |
| --- | --- |
| 单文件体积 | 每个产物约 4 MB（内联完整引擎，保证永不过期、离线可开） |
| HTTP 模式寿命 | 进程退出即失效，适合「现在看」；发给别人用 `render` / `html` |
| 截图功能 | `shot` 子命令需另装 `playwright-core` + 本地 Edge/Chrome，其余功能零依赖 |
| 数学公式 | 不支持（引擎本身的硬缺口） |

## 数据与隐私

全部本地。不上传、不联网、不收集。渲染产物在 `~/.mdlens/view/`，自动保留最近 30 个，超出按时间清理。
