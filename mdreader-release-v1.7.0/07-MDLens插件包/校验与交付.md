## 本轮做了什么

1. **引擎升级到 v1.7**：包里的 `engine/MDLens.html` 原是 11-15 基于旧版 MDReader（4.24MB）生成的。用 `scripts/build-engine.py` 从今早的 `MDReader/dist/MDReader.html`（4.75MB）重建，产出 4.66MB 新引擎——外壳剥离 CSS / 引擎接口 / 桥接层全部 OK。旧引擎备份在 `/tmp/MDLens.engine.old.html`。
2. **全量测试通过**：`node scripts/test-all.cjs` **52 PASS / 0 FAIL**（A–E 五组，含浏览器渲染质量 17 项 + 表格自动出图 6 项）。测试用现成 `playwright-core`（NODE_PATH 指向 sci-hud），**没有打进包**。
3. **零依赖确认**：bin/lib 只 require Node 内置模块（`node:fs` / `node:path` / `node:http` 等），`playwright-core` 仅 `shot` 截图子命令可选需要。用户装 Node 18+ 即可，无需 npm install。
4. **包内文件**：核心程序（bin / lib / engine / examples / scripts）+ README + package.json + 新写的《安装与使用.md》。排除了 `_shots/`、engine 临时截图等开发素材。
5. **解压后实测**：在临时目录解压 zip → `doctor` 显示 `engine: OK 4.66 MB` → 真实渲染 `examples/ai-report.md` 成功（4.67MB 单文件，自动开浏览器）。
