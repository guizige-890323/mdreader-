## 四、命名与版本规则（这次统一过）

| 位置 | 规则 | 例 |
| --- | --- | --- |
| 产物文件名 | `<产品>-<形态>-v<版本>.<ext>` | `MDReader-便携版-v1.7.0.zip` |
| 安装包 | `<产品> Setup <版本>.exe`（保留空格，与 electron-builder 一致） | `MD Reader Setup 1.7.0.exe` |
| 产品内版本串 | 显示到次版本号 | `MD Reader v1.7 · 离线版` |
| tag | `v<主>.<次>.<修订>` | `v1.7.0` |
| 输出目录 | 所有产物统一落 `发布包/`，已进 `.gitignore` | — |
