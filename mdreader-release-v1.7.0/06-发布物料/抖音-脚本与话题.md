# 抖音脚本 · 竖版 9:16

> 抖音和视频号不是一套东西。抖音要**前 1.5 秒给结论**，节奏更快，字幕更大，可以有口播。
> 给两个版本：15 秒（冲完播）、35 秒（讲清楚）。

---

## 发布信息

- **标题**（≤30 字）：`4.6 MB 的 Markdown 阅读器，双击就开#开源`
- **话题**：`#Markdown` `#效率工具` `#开源软件` `#程序员日常` `#独立开发者`
- **@**：不 @
- **位置**：不限
- **发布时间**：12:00–13:00 或 19:00–21:00
- **置顶评论**：`GitHub 搜 mdreader，MIT 开源，下载暂未开放，先点 Star`

## 抖音的三条铁律

1. **不要出现 logo 开场**，前 1.5 秒必须是动作或冲突
2. **字幕要比你觉得的再大一号**，手机竖屏看，小字等于没有
3. **不要念参数**（"支持 40 种语言高亮"没人听），只念场景和结果
