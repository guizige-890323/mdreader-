## 正文

### 一

这两年，你可能已经攒了一堆 `.md` 文件，只是自己没注意。

用 AI 查东西、写方案、整理笔记——DeepSeek、豆包、Kimi、ChatGPT，随便哪个——它给出的回答其实都是 Markdown：有标题、有加粗、有分点、有表格，还有代码块，排版得清清楚楚。你想留着以后慢慢看，一导出，就是个 `.md` 文件。

然后你打开它，傻眼了。

不管是记事本还是 Word，扑面而来的是一堆符号：`##` 是标题，`**` 是加粗，`-` 是列表，还有一行行的三反引号。符号比正文还显眼，眼睛根本抓不住重点。内容明明很有用，读起来却累得慌。

**这不是你的问题，是 Markdown 的天生毛病。**

它本来是给机器看的——干净、结构化、好处理。可现在，AI 把海量的 Markdown 塞进了普通人的生活：对话记录、生成的文档、社区教程、笔记软件里的笔记……人人都在产 `.md`，却没有几个人真的愿意盯着那些符号读。

想读得舒服点，路只有两条：装个代码编辑器，先等它启动，再装插件；或者把内容粘到某个在线网站——然后开始纠结，我这份东西要不要传上去。

**只是想把一份文档读舒服，为什么要付这么多代价。**

MD Reader 就是为这件事做的。它只有一个 HTML 文件，**4.6 MB**，双击就开，不装、不联网、不登录。你把 `.md` 拖进去，那些符号就变成干净的标题、加粗和表格，是一份能安安静静读完的页面。

就这样。它没有别的野心。

### 二、四个词，四件具体的事

我不太喜欢用形容词介绍产品，所以每一句都给出核对方式。

**小而美。**
一个 4.6 MB 的 HTML 文件就是完整程序。marked、highlight.js、mermaid 全部内嵌，运行时**零网络请求**——你可以拔掉网线再打开它，或者自己 `grep` 一遍源码看有没有 `fetch`。作为对照，同类工具里 MarkText 是 64k star，装机包几十 MB 起。

**有态度。**
它明确**不做**四件事：不做账号、不做云同步、不做数据上报、不内置 AI 摘要。不是做不到，是不想。一个只读文档的工具，没有理由知道你是谁、你在读什么。做不到的地方我也写在 README 里——比如不支持数学公式，这就是硬缺口，别指望它。

**有审美。**
两套排版皮肤不是换个边框：卡片模式按二级标题把长文切成带编号的面板，纸张模式是连续长文加页边装订线，连标题字体都从无衬线换成衬线。三套主题（浅色 / 深色 / 护眼）与皮肤正交，四套文档风格统一驱动图表配色、流程图强调色和代码高亮——**整篇文档是一种气质，不是一个色块**。

**有温度。**
护眼配色是低蓝光暖米黄，对比度过 WCAG 标准；没有广告位、没有弹窗、没有「升级到专业版」。装完就是一个安静的窗口，关掉就没了。它不会在后台做任何事。

### 三、这一版新增的东西

如果你之前看过 v1.3，这次隔了四个小版本，主要补的是「把图看懂」这件事。

**每张流程图可以有自己的结构。**
原来「结构」是全局设置，一份文档里所有图都长一个样。现在结构选择器搬到每张图自己的右上角，按源码内容记住选择。5 种结构 × 5 种风格 = 25 种观感，切换结构时你的文字、颜色、增删的节点都会保留。

**代码块里画的架构图，能变成真的图。**
很多人的架构图是用 `┌─┐│└┘` 这类框线字符画的。现在把它放进代码块，MD Reader 会用纯算法（不联网、不调模型）识别成节点和连线，渲染成可拖拽、可改字、可导出的矢量流程图。中英混排、边框漂移、缺一条顶边，都能认。

**六种图表。**
表格点一下就出图：柱状、折线、趋势面积、环形饼图、玫瑰图，或者让程序按数据形状自己挑。饼图是按 `数值 ÷ 总数 × 360°` 精确分角的，不是六等分——0.3% 的那一项真的只有 1.08 度。

**界面能切英文了。**
设置里可以选简体中文 / English / 跟随系统。你自己打开的 `.md` 永远不会被翻译，翻的只是界面。

### 四、它不解决的问题

写清楚这一点，比吹功能重要。

- **不能当写作工具。** 编辑做到「够改一行」，按块改、`Ctrl+S` 写回原文件。要写长文去用 Typora。
- **不支持数学公式。** 没有 KaTeX / MathJax，LaTeX 会以源码显示。
- **iOS 不能设默认打开程序。** 系统不允许，这不是我能绕过的，PWA 主屏幕版已经是能力上限。
- **macOS 要自己编译。** 配置和脚本都在仓库里，但我没有 Mac 实测。

### 五、怎么拿到

**源码已经开源在 GitHub：`guizige-890323/mdreader`，MIT 协议。**

预编译的安装包这次先不放出来——我想先让代码在阳光下放几天，确认没有低级问题，再开下载。**想要的话，点个 Star，开放下载时会在动态里看到。**

急着用也行，仓库里就带着构建好的成品：克隆下来，直接双击 `MDReader/dist/MDReader.html` 就能用，和你下载安装包是同一个文件。

如果你更习惯「装成一个应用」，等下载开放；如果你只是偶尔看几份文档，那个 HTML 文件本身就够了。

### 六、最后

这个项目没有公司、没有融资、没有增长指标。它开始于我自己想好好看一份排查手册，做完之后发现身边的人也在用，就开源了。

**它不会变成一个大而全的工具。** 有人提过加插件市场、加云同步、加 AI 总结，我大概率都不会做——不是因为清高，是因为一旦做了，它就不再是那个「4.6 MB，双击就开」的东西了。

如果你也觉得「看文档」这件事值得被认真对待，Star 一下，或者提个 Issue 告诉我哪里难用。一个人的项目，响应可能慢一两天，但每条都会看。
