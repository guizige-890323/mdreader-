# 视频号脚本 · 45 秒

> 视频号的推荐逻辑吃**完播率 + 互动**。45 秒是安全区间，前 3 秒必须给冲突，不要 logo 开场。
> 形式：录屏 + 大字幕，无人声也能看懂（很多人静音刷）。

---

## 标题（发布时填）

**A**｜一个 4.6 MB 的文件，替掉了我的 Markdown 编辑器
**B**｜双击就能看，不联网不登录
**C**｜我把「看文档」这件事，做小了一点

## 分镜脚本（45 秒）

| 时间 | 画面（录屏） | 字幕（大字，居中偏下） | 备注 |
| --- | --- | --- | --- |
| 0–3s | 桌面，双击一个 `.md` 文件 | **看一份文档，为什么要开 100 MB 的软件？** | 冲突钩子，字要最大 |
| 3–8s | 窗口秒开，卡片式分节，滚动两屏 | 双击就开　4.6 MB　不装不联网 | 展示速度感，不要停顿 |
| 8–15s | 点表头排序 → 点「图表」→ 柱状图出来 → 切环形饼图 | 表格能排序，还能一键出六种图 | 饼图那段停 1 秒，视觉最强 |
| 15–24s | 打开流程图 → 拖一个节点 → 连线跟着走 | 流程图能直接拖，导出就是改完的样子 | 拖拽是「哇」点，动作要慢 |
| 24–32s | 切纸张皮肤 → 切深色 → 切护眼 | 两套皮肤，三套主题 | 三连切，节奏卡点 |
| 32–38s | 粘一段 `┌─┐│└┘` 架构图进代码块 → 变成矢量图 | 代码块里画的架构图，能变成真的图 | 全片最反直觉的一下 |
| 38–45s | 设置里切成 English → 界面变英文 | 中英双语 · 开源免费 · MIT | 结尾不喊关注，只给事实 |

**BGM**：轻快的 lo-fi / 电子，音量压到 -22 dB，别盖字幕。
**转场**：硬切，不要花哨转场（会显得廉价）。

## 发布信息

- **话题**：`#Markdown` `#开源` `#效率工具` `#独立开发` `#程序员`
- **位置**：不填（会显得像广告）
- **简介**：双击就能看本地 .md，不联网不登录。开源 MIT，GitHub 搜 mdreader。
- **@**：不 @ 任何人
- **合集**：新建「我的开源小工具」，后续同类视频都进这个合集（涨粉靠合集，不靠单条）

## 拍之前先做这三件事

1. **分辨率**：录屏用 1920×1080，窗口别全屏（留出桌面边缘更有真实感）
2. **鼠标**：把系统指针调大一号，观众才看得见你在点哪
3. **清场**：关掉所有通知、隐藏桌面文件、浏览器只留一个标签
